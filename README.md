# 🌎 Daily Language

**The Web App built to help you to excel at the language of your choice. It consists of 3 exercises:**
*vocabulary
*grammar
*writing
**that you can and should practice daily.**

## 0. Prerequisites
This project uses node packet manager, python flask and Gemini API calls.

## 1. How to use it?
After setting up your local environment open two terminal windows. Run `npm run dev` and `npm run api`. Access [http://localhost:5173/](http://localhost:5173/)

## 2. How to setup it up?
1. Download the local copy of this repository.
2. Create the .env file in the _api_ directory. 
3. Generate Google Gemini API key (free of charge): 
   [Tutorial](https://ai.google.dev/gemini-api/docs/api-key "https://ai.google.dev/gemini-api/docs/api-key")
4. Inside .env file create the key variable `GEMINI_API_KEY=` and populate it's value.
5. Save the file.
